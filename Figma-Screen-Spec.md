# Figma Wireframe Specification

Create low-fidelity screens for:

## Screen 1 — Charging Home
- Battery %
- Current charging power
- Estimated completion time
- Charging state
- Stop charging CTA

## Screen 2 — Adaptive Charging
Headline: “Charging optimized”
Subtext: Explain the reason in simple language.
Show:
- Current ETA
- Previous ETA
- Charging state
- Learn more

## Screen 3 — Why did charging slow down?
Explain:
- battery/environment conditions
- that charging continues
- updated ETA
- safety/health language only where validated

## Screen 4 — Charging History
Show:
- date
- duration
- energy delivered
- completion
- optimization events

## UX principle
Do not make a normal optimization event look like a dangerous battery failure.
